# Project Brief — AgenciAlquimia 🎯

> **La "Constitución" y visión fundacional de AgenciAlquimia.** Define la propuesta de valor, los objetivos de negocio y el alcance del sistema como Estudio de Arquitectura Web & Ecosistemas de IA a Medida.

---

## 1. Visión y Propuesta de Valor

**AgenciAlquimia** es un estudio de **Arquitectura Web de Nueva Generación e Infraestructura con Inteligencia Artificial a Medida** para empresas y negocios en **Santiago de Compostela, Galicia y España**.

* **Lema Corporativo:** *"Arquitectura Web de Nueva Generación e Infraestructura con IA a Medida."*
* **Misión:** Transformar la operativa de las empresas diseñando aplicaciones web de alta velocidad, microservicios backend especializados y ecosistemas de automatización propios sin ataduras a plataformas de terceros.
* **Propuesta Central:** Desarrollo a medida en Next.js 15, microservicios en Python/FastAPI, orquestación de datos privada (n8n self-hosted) y paneles de control propietarios sobre infraestructura soberana (VPS / Docker / PostgreSQL).

---

## 2. Objetivos Principales del Proyecto

1. **Arquitectura Web Next-Gen con IA Embebida:**
   * Aplicaciones y páginas web en Next.js 15 + React 19 con rendimiento WPO < 1s (Lighthouse 100/100).
   * Interfaces cognitivas interactivas con agentes conversacionales embebidos en el diseño.

2. **Microservicios Backend & Algoritmos a Medida:**
   * Motores en Python (FastAPI Sidecar) para extracción de datos de mercado (*Lead Hunter*), scoring predictivo con Machine Learning y generación instantánea de informes y presupuestos en PDF.

3. **Orquestación Operativa & Sincronización Total:**
   * Workflows privados en n8n conectando la web con software de facturación (Holded, FacturaDirecta), CRM, calendarios y canales omnicanal (WhatsApp API, Email, Notificaciones internas).

4. **Paneles de Control & Soberanía de Datos:**
   * Dashboards privados a medida para evitar pagar cuotas mensuales de herramientas SaaS genéricas. Alojamiento en servidores VPS dedicados con cumplimiento RGPD estricto.

---

## 3. Alcance del Sistema (Scope)

* **En Alcance:**
  * Frontend público Next.js 15 (App Router) + React 19 + TailwindCSS v4.
  * API Routes seguras con validación de tokens JWT y firmas HMAC SHA-256.
  * Orquestador n8n (`cerebro.agencialquimia.com`) para sincronización y flujos multicanal.
  * Base de datos PostgreSQL en instancia local Supabase (Coolify VPS).
  * Panel administrativo protegido (`/admin`) con Kanban de leads y control de ejecuciones.
  * Microservicio Python 3.12 (FastAPI + Uvicorn) en red interna Docker.

* **Fuera de Alcance:**
  * Aplicaciones móviles nativas (canalizado mediante Web Responsiva PWA y WhatsApp API).
  * Pasarelas de checkout en la web pública (las ventas se canalizan mediante propuestas de arquitectura y sesiones estratégicas).
